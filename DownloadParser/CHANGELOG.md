# 변경 이력 (Changelog)

보자기카드 다운로더의 버전별 변경 사항을 기록합니다.
형식: 최신 버전이 맨 위. 버전 = `src/config.py` 의 `APP_VERSION` 과 빌드된 exe 이름에 반영됩니다.

---

## v2.0.10 (2026-06-24)
- 시작 시 검증 단계 로딩 문구를 "관리자 ID 확인 중…" → **"관리자 정보 확인 중…"** 으로 변경
  (ID·비밀번호를 함께 입력받는 흐름과 일치, 혼동 감소).

## v2.0.9 (2026-06-24)
- **관리자 ID·비밀번호를 한 입력창에서 함께** 받도록 변경 (기존 2단계 → 1단계).
  - dialogs.prompt_credentials 추가 (ID 칸 + 비밀번호 칸, 비밀번호 마스킹)
  - 첫 실행/변경 모두 통합 입력창 사용. 푸터 링크를 "관리자 ID · 비밀번호 변경" 하나로 통합.

## v2.0.8 (2026-06-24)
- **시작 UX 개선**: 관리자 ID·비밀번호 입력창이 뜰 때 "불러오는 중" 로딩 오버레이를 내림.
  (입력 대기와 로딩 표시가 동시에 보이던 모순 제거 — 입력을 마친 뒤에만 로딩 표시)

## v2.0.7 (2026-06-24)
- 로그인 비밀번호 입력창 안내문을 **"보자기카드 로그인 비밀번호를 입력하세요."** 한 줄로 간소화.

## v2.0.6 (2026-06-23)
- **수정 탭 다운로드 대상 수정**: 기존엔 수정 탭에서도 '작업 원본' zip 을 받았으나,
  이제 **'수정요청 이미지'(수정내역에 올라온 이미지)** 를 받는다.
- 수정요청 이미지는 **로그인해야만** 조회되므로(`mov_list_sian_list.php`), 로그인 기능 추가.
- **로그인 비밀번호**를 처음 한 번 입력받아 PC 에 암호화 저장(관리자 ID 와 동일 방식, DPAPI).
  푸터에 **"비밀번호 변경"** 추가. 비밀번호 입력창은 마스킹(●) 처리.
- 수정 탭 주문은 고객별 폴더(`..(수정)`)에 수정요청 이미지들을 저장.
- 등록 탭은 기존과 동일(zip).

### 버전 올리는 방법 (개발자용)
1. `src/config.py` 의 `APP_VERSION` 수정 → 제목 표시줄·푸터에 자동 반영.
2. `build.bat` 의 `--name "보자기카드 다운로드 vX.Y.Z"` 도 같은 버전으로 수정.
3. 이 파일(CHANGELOG.md) 맨 위에 새 버전 항목 추가.
4. `build.bat` 실행해 재빌드.
