1처음 실행 · 관리자 ID

프로그램을 처음 켜면 보자기카드 관리자 ID를 한 번 입력해야 합니다.

  • 실행하면 “준비 중…” 로딩 화면이 먼저 뜹니다.
  • 저장된 ID가 없으면 관리자 ID 입력창이 나타납니다. ID를 입력하고 확인을 누르세요.
  • 입력한 ID는 이 PC에 안전하게 저장되어, 다음부터는 다시 묻지 않습니다.
✓ 한 번만 입력하면 됩니다 같은 PC에서는 이후 자동으로 사용됩니다. ID는 암호화되어 저장되며(Windows), 프로그램을 다른 PC로 복사해도 ID는 따라가지 않아 그 PC에서 새로 입력해야 합니다(보안).
⚠ “주문을 찾지 못했습니다” 창이 뜨면 입력한 ID로 주문이 하나도 조회되지 않은 경우입니다. ID가 정확하다면 [예] 이 ID로 계속을, 오타가 의심되면 [아니오] 다시 입력을 누르세요.

관리자 ID를 바꾸려면

화면 맨 아래 왼쪽의 “관리자 ID 변경” 글씨를 클릭하면 다시 입력할 수 있습니다.

3등록 / 수정 탭

표 오른쪽 위의 [등록 | 수정] 버튼으로 두 목록을 전환합니다.

  • 등록 — 새로 등록된 주문 자료(zip 압축 파일)
  • 수정 — 수정 요청된 자료. 받은 파일 이름 뒤에 (수정)이 붙어 등록본과 섞이지 않습니다.
    예) 0414_0425 장형구 식전영상 (수정).zip
💡 전환은 즉시 처음 켤 때 등록·수정 두 목록을 모두 불러와 두기 때문에, 탭을 누르면 기다림 없이 바로 바뀝니다. 최신 상태로 다시 받고 싶으면 새로고침을 누르세요(두 탭 모두 갱신).

4저장 폴더 설정

  • 폴더 선택 버튼으로 저장 위치를 고르거나, 입력칸에 경로를 직접 적고 Enter.
  • 폴더 열기로 현재 저장 폴더를 탐색기에서 바로 엽니다.
  • 폴더를 바꾸면 목록의 ‘다운완료’ 표시가 그 폴더 기준으로 다시 계산됩니다.
⚠ 이미 받은 파일은 자동으로 건너뜁니다 저장 폴더에 같은 이름 파일이 이미 있고 크기가 정상(50KB 이상)이면 ‘다운완료’로 보고 다시 받지 않습니다. 다시 받고 싶으면 그 파일을 폴더에서 지운 뒤 새로고침하세요.

현재 선택 수는 표 아래 “선택 N건 / 전체 M건”으로 표시됩니다.

6기간으로 한 번에 선택

특정 날짜 범위의 주문을 한꺼번에 받고 싶을 때 사용합니다.

  • 오른쪽 위 기간(MMDD) 칸에 시작일과 종료일을 4자리(월월일일)로 입력. 예) 0531 ~ 0607
  • 선택 날짜 다운로드 버튼을 누르면 그 기간의 주문이 선택되어 바로 다운로드됩니다.
💡 날짜 자동 채움 목록을 불러오면 시작·종료일 칸이 현재 목록 범위로 자동으로 채워집니다. 그대로 쓰거나 수정하세요.

7다운로드 · 중지

  • 받을 항목을 선택합니다(위 5·6번).
  • 오른쪽 아래 선택 항목 다운로드를 누릅니다.
  • 진행 막대와 “진행 상황” 로그에서 상태를 확인합니다.
  • 도중에 멈추려면 중지 버튼을 누릅니다.
💡 다운로드 중에 다음 작업을 ‘예약’할 수 있어요 (순차 대기열) 한 다운로드가 진행되는 동안 탭을 자유롭게 오갈 수 있고, 다른 탭(또는 같은 탭)에서 항목을 골라 선택 항목 다운로드를 다시 누르면 곧바로 시작하지 않고 대기열에 쌓입니다. 현재 다운로드가 끝나면 대기열의 다음 작업이 자동으로 이어서 실행됩니다.
예) 등록 탭을 받는 중에 → 수정 탭으로 가서 항목 선택 후 다운로드 누름 → 등록이 끝나면 수정이 자동 시작.
  • 대기 중인 작업이 있으면 버튼 줄에 ⏳ 대기열 수정 12건 같은 표시가 계속 떠 있습니다. 이 표시가 보이면 “받을 게 예약돼 기다리는 중”, 안 보이면 “예약된 게 없는 상태”로 한눈에 구분됩니다.
  • 한 번에 하나씩 순서대로 받으므로 서버에 무리가 가지 않습니다.
  • 중지를 누르면 현재 다운로드와 함께 대기 중이던 작업도 모두 취소됩니다(표시도 사라짐).
⚠ 일부 파일이 실패하면 네트워크 상황에 따라 몇 건이 실패할 수 있습니다. 실패한 파일은 받지 않은 상태로 남으므로, 다시 한 번 다운로드를 실행하면 빠진 것만 채워집니다(이미 받은 건 자동 스킵).

8상태 표시 읽는 법

표시의미
대기 / 받기 전아직 다운로드하지 않은 주문
다운완료 (스킵)저장 폴더에 이미 정상 파일이 있어 건너뜀
빠른 처리 색상 행빠른제작 주문(우선 처리 대상)
진행률 막대다운로드 중인 전체/개별 파일 진행 상태

자세한 기록은 “로그 폴더 열기” 버튼으로 로그 파일을 확인할 수 있습니다.

9여러 PC에서 쓰기

여러 대(예: 4대)의 PC에서 같은 프로그램을 쓸 수 있습니다.

  • 각 PC에 프로그램을 복사하고, PC마다 관리자 ID를 한 번씩 입력하면 됩니다(같은 ID 사용 가능).
  • ID는 PC마다 따로 암호화 저장되므로 안전합니다.
⚠ 동시에 많이 받을 때 여러 PC가 동시에 대량 다운로드하면 서버 부하로 일부 파일이 실패할 수 있습니다. 그럴 땐 다운로드를 한 번 더 실행하면 빠진 파일이 채워집니다. 가능하면 PC들의 다운로드 시점을 조금씩 어긋나게 하는 것도 도움이 됩니다.

10자주 묻는 질문

Q. 켤 때마다 관리자 ID를 또 물어봐요.
A. 정상적으로는 한 번만 묻습니다. 매번 묻는다면 저장 파일이 지워졌거나 다른 PC/계정일 수 있습니다. ID를 다시 입력하면 됩니다.
Q. 올바른 ID를 넣었는데 “주문을 찾지 못했습니다”가 떠요.
A. 그 ID로 조회되는 주문이 0건일 때 나오는 안내입니다. ID가 맞다면 [예] 이 ID로 계속을 누르세요. 목록은 비어 보일 수 있습니다.
Q. 받았는데 목록이 비어 있어요.
A. 등록/수정 탭을 확인하고, 새로고침을 눌러 보세요. 기간 필터가 좁게 설정돼 있지 않은지도 확인하세요.
Q. 같은 파일을 다시 받고 싶어요.
A. 저장 폴더에서 그 파일을 지운 뒤 새로고침하면 ‘대기’ 상태가 되어 다시 받을 수 있습니다.
Q. 수정본과 등록본이 헷갈려요.
A. 수정 탭에서 받은 파일은 이름 뒤에 (수정)이 붙어 있어 같은 폴더에서도 구분됩니다.
